Three layers of protection for every file

Each protected file is guarded three independent ways, so a change can't slip through and can't be covered up.

Layer 1

A fingerprint of the contents

FileVow calculates a SHA-256 fingerprint of every file. Change a single letter and the fingerprint is completely different, so any edit is noticed.

Layer 2

A seal only you can make

Each fingerprint is sealed with your personal RSA signing key. Nobody can quietly rewrite FileVow's records to hide a change, because they can't forge your seal.

Layer 3

An encrypted backup copy

FileVow keeps an encrypted copy of every approved version. You can compare it line by line with what changed and restore it instantly.
